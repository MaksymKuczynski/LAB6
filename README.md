# Лабораторна робота № 6. Використання та створення модулів та пакетів у Python

## Мета

Ознайомитися з концепцією модулів та пакетів у мові програмування Python, навчитися створювати власні модулі та пакети, а також використовувати готові модулі та пакети з стандартної бібліотеки й сторонніх джерел. Поглибити знання про структурування коду, повторне використання коду та організацію великих проєктів. Розвинути навички самостійного вивчення документації та роботи з різними інструментами розробки.

## Завдання для всіх варіантів

1.  **Створити власний модуль** з декількома функціями, що виконують певні корисні операції.
2.  **Створити пакет**, який містить декілька модулів.
3.  **Написати програму**, яка імпортує та використовує створені модуль та пакет.
4.  **Використати принаймні один модуль** зі стандартної бібліотеки Python.
5.  **Використати принаймні один сторонній пакет**, встановлений за допомогою менеджера пакетів `pip`.
6.  **Задокументувати створені модулі та пакети**, використовуючи docstrings.
7.  **Написати тести** для перевірки функціональності створених модулів та пакетів.
8.  **Надати відповідь на контрольне запитання** для вашого варіанту.

## Інструкція з виконання

### 1. Налаштування проєкту

*   Клонуйте цей репозиторій на ваш локальний комп'ютер.
*   Встановіть необхідні пакети, використовуючи файл [`requirements.txt`](requirements.txt):
    ```bash
    pip install -r requirements.txt
    ```

### 2. Реалізація вашого варіанту

*   Оберіть один із варіантів зі списку нижче.
*   Дотримуючись вимог вашого варіанту, створіть необхідний пакет та модулі всередині директорії `src/`. Наприклад, для Варіанту 1, вам потрібно буде створити директорію `src/calculator`, а в ній файли `basic_operations.py`, `advanced_operations.py` та файл `__init__.py`.
*   Напишіть основну частину вашої програми у файлі [`src/lab6.py`](src/lab6.py). Цей файл повинен імпортувати та використовувати функції зі створеного вами пакета, модуля стандартної бібліотеки та стороннього пакета.
*   Напишіть юніт-тести для ваших функцій у файлі [`tests/test_lab6.py`](tests/test_lab6.py). Ви можете запустити тести з кореневої директорії проєкту за допомогою наступної команди:
    ```bash
    python -m unittest discover tests
    ```

### 3. Здача роботи

1.  Заповніть файл [`REPORT.md`](REPORT.md) наступною інформацією:
    *   Повний код ваших модулів та основної програми.
    *   Пояснення до вашого коду.
    *   Відповідь на контрольне запитання для вашого варіанту.
    *   Ваші висновки з лабораторної роботи.
2.  Зробіть коміт та відправте ваші зміни до вашого GitHub репозиторію.
